# 《足球命格》产品动线设计

产物：逐屏动线 + 各屏文案位。不含文案库、结果命名、视觉方案、技术实现。

分两期：
- **Phase 1（先上）**：单人测试 + 单人卡传播闭环。
- **Phase 2（紧跟）**：拼队玩法——队长发起、成员加入、生成赛前 11 人合影。
- Phase 1 的设计必须为 Phase 2 预留接口（见第 6 章）。

> ⚠️ **硬性前置依赖｜结果持久化**
> Phase 1 即便不做账号，也**必须**把每次测试结果存一份、绑定一个 ID。
> 这是 Phase 2 拼队的命脉——拼队靠「球队链接归集成员结果」，若 Phase 1 做成纯无状态（测完即走、不存），Phase 2 直接卡死、需推翻重做。
> 此项非「优化」，是 Phase 2 能否成立的前提。详见第 6 章。

## Phase 1 · 单人测试

### 1. 动线总览

两条入口，在「输入 → 揭晓 → 结果页 → 传播」合流。

```
   【A 普通入口】              【B 朋友落地页 · 主力】
   A1 强钩子页               B1 朋友结果落地页
   钩子+示例+承诺            朋友结果+一句挑衅
        │ 测我的                  │ 测我的
        └──────────┬──────────────┘
                   ▼  合流
        ① 输入流程（点选为主）
        性别·生日·城市·球风·位置
                   ▼
        ② 揭晓动效 1.5–2.5s
                   ▼
        ③ 结果页（大结果名+角色图+金句）
           主动作：保存图片
           预留位：组一支队（Phase 2 点亮）
              │
              ▼
        ④ 传播 发群/朋友圈
              │
              ▼
      发出的图 = 别人的 B1（闭环）
```

### 2. 字段设计（屏 ①）

| 字段 | 必填/选填 | 交互 | 作用 |
|---|---|---|---|
| 性别 | 必答 | 点选 | 生成对应性别角色 |
| 出生日期 | 必填 | 日期选择器 | 命格感主锚点 |
| 出生时间 | 选填 | 点选 | 可跳过 |
| 出生地 | 选填 | 城市快捷选+搜索 | 城市级，不手打 |
| 球风题 | 必答 | 点选 | 埋「我以为 vs 系统判定」反差 |
| 位置题 | 选填 | 点选 | 可跳过 |
| 昵称 | 选填 | 保存图片时再问 | 卡片个性化 |

必答三项：性别、生日、球风。全程点选，无打字。

### 3. 逐屏动线

#### 屏 A1 强钩子页（普通入口首屏）
- 看到：强钩子句、主视觉、2–3 个示例结果、几步出结果承诺
- 可做：点 CTA「测我的命格」
- 去哪：→ 屏 ①
- 文案位：主钩子句 / 示例结果名 ×2–3 / 承诺句 / CTA

#### 屏 B1 朋友结果落地页（主力入口首屏）
- 看到：朋友结果名+角色图、一句挑衅、CTA「测我的命格」
- 可做：点 CTA
- 去哪：→ 屏 ①
- 不展示朋友完整解读
- 文案位：挑衅/邀约句、CTA

#### 屏 ① 输入流程
- 看到：顶部轻提示、步骤指示、点选控件
- 可做：完成必答项；选填项可跳过
- 去哪：完成必答 → 屏 ②
- 文案位：顶部提示句 / 选填安抚句 / 球风题题干 / 位置题题干 / 按钮

#### 屏 ② 揭晓动效
- 看到：1.5–2.5s 动画、「正在分析」过场
- 可做：等待
- 去哪：自动 → 屏 ③
- 文案位：计算感过场句

#### 屏 ③ 结果页
- 看到（第一屏）：大结果名、角色图（含性别）、金句
- 看到（下滑）：展开解读、国家命格、位置
- 可做：保存图片（主）；再测一次（次）；组一支队（预留位，Phase 2 点亮）
- 去哪：保存图片 → 屏 ④；再测 → 屏 ①；组一支队 → 屏 ⑥（Phase 2）
- 文案位：结果名 / 金句 / 保存按钮 / 保存后引导句 / 次级动作按钮

#### 屏 ④ 传播
- 看到：保存成功确认+「去发给朋友」引导；卡面中部回流抓手
- 可做：切微信/小红书发图配话
- 去哪：发出的图 → 别人的 B1
- 文案位：可发群一句话 / 卡面回流抓手

### 4. 分享方式

| 方式 | 结论 |
|---|---|
| 保存图片 | 主推（已确认） |
| 一键发微信 | 加分项，非 MVP 前提 |
| 一键发小红书 | 保存图→跳小红书→自己发，引导即可 |
| 扫码 | 仅线下/跨设备，不进主动线 |

### 5. Phase 1 文案位汇总

| 屏 | 文案位 | 任务 |
|---|---|---|
| A1 | 主钩子句 | 点破玩法+身份好奇 |
| A1 | 示例结果名 ×2–3 | 引发「我会是哪个」 |
| A1 | 承诺句 | 打消冗长表单顾虑 |
| A1 | CTA | 前进动作 |
| B1 | 挑衅/邀约句 | 激发围观者「那我呢」 |
| B1 | CTA | 围观转「我也来」 |
| ① | 顶部提示句 | 快、轻、无需打字 |
| ① | 选填安抚句 | 降低跳过负担 |
| ① | 球风题题干 | 点选提问，埋伏笔 |
| ① | 位置题题干 | 轻问，可跳过 |
| ② | 计算感过场句 | 强化在算 |
| ③ | 结果名 | 高识别有梗身份标签 |
| ③ | 金句 | 「这就是我」，传播核心 |
| ③ | 保存按钮 | 动作明确 |
| ③ | 保存后引导句 | 保存导向传播 |
| ④ | 可发群一句话 | 替用户省配文 |
| ④ | 卡面回流抓手 | 告知去哪测 |
| 全站 | 娱乐免责小字 | 切割 IP 与「当真」风险 |

## 6. Phase 1 必须为 Phase 2 预留的接口

Phase 1 开发时即落地，否则 Phase 2 需推翻重做：

> ⚠️ **最关键一项：结果持久化（Phase 2 命脉）**
> 拼队靠「球队链接归集成员结果」。每个成员点链接、测完后，其结果必须能被存下、归到某支队、供队长调出。
> Phase 1 哪怕无账号，也必须做掉「结果存一份 + 给个 ID」。做成纯无状态 = Phase 2 不可能实现。
> 优先级：与单人主流程同级，不可砍。

| 预留项 | 要求 | 等级 |
|---|---|---|
| 结果可持久化 | 每次测完结果绑定一个 ID 存下、之后可调出（即便无账号），供拼队归集 | **硬依赖·不可砍** |
| 结果带「位置/阵型」字段 | 每个命格结果附「建议场上位置」，否则无法排 11 人站位 | 硬依赖 |
| 角色形象可复用 | 角色立绘做成可单独抠出、可缩放，能排进合影队形，不写死在单人卡版式 | 硬依赖 |
| 结果页「组一支队」入口位 | UI 预留按钮位，Phase 1 不接功能，Phase 2 点亮 | 低成本预留 |

## Phase 2 · 拼队玩法

模型：队长发起 → 成员扫码/点链接加入并测 → 成员结果自动汇到队长 → 队长挑人排位 → 生成赛前 11 人合影。

合影形态：11 个命格角色穿统一队服、站赛前合影队形、每人标命格名+昵称。**非真人脸**（避开头像/肖像风险，复用单人角色素材）。

### 7. 拼队动线总览

```
【队长线】                          【成员线】
单人测完(屏③) 点「组一支队」          收到队长分享的「加入球队」链接
   ▼                                    ▼
屏⑥ 创建球队                        屏⑧ 成员落地页
 生成球队链接/码,自己成为队长(第1人)    「XX的球队已有N人,来占个位」
   │ 分享链接到群                       │ 点「测我的命格并加入」
   ▼                                    ▼
屏⑦ 球队管理页(队长专属)            （走单人①②③,结果归入该队）
 实时看到所有加入者命格卡               ▼
 从N人挑11人+排位置                  屏⑨ 加入成功页
   ▼                                「已加入,等队长发首发」
屏⑩ 生成赛前11人合影                   (成员端结束,可再把链接转给别人)
 11个命格角色穿队服站位
 每人标命格名+昵称
   │ 保存合影
   ▼
 发回群 → 又成为新的「加入球队」入口(闭环)
```

### 8. 拼队逐屏动线

#### 屏 ⑥ 创建球队（队长）
- 看到：球队名输入、生成的球队链接/码、「分享到群」按钮
- 可做：命名球队；分享链接；自己作为第 1 名成员
- 去哪：分享后 → 屏 ⑦
- 进入：从屏 ③「组一支队」
- 文案位：建队引导句 / 分享按钮 / 球队名占位提示

#### 屏 ⑦ 球队管理页（队长专属）
- 看到：成员实时列表（每人命格卡，随加入增长）、已选/未选标记、阵型选择
- 可做：从 N 人中挑 11 人；为每人排位置；选阵型；继续分享链接拉人
- 去哪：挑满并确认 → 屏 ⑩
- 文案位：成员列表空状态句 / 「再拉几人」催人句 / 生成按钮

#### 屏 ⑧ 成员落地页（成员入口首屏）
- 看到：「XX 的球队已有 N 人」、已加入成员的命格预览、CTA「测我的命格并加入」
- 可做：点 CTA
- 去哪：→ 走单人流程（屏 ①②③），结果归入该队 → 屏 ⑨
- 文案位：球队号召句（带人数，制造从众）/ CTA

#### 屏 ⑨ 加入成功页（成员）
- 看到：「你已加入 XX 的球队」、自己的命格卡、等待提示
- 可做：把球队链接再转给别人；保存自己的单人卡
- 去哪：转链接 → 别人的屏 ⑧（闭环）
- 文案位：加入确认句 / 「拉更多人」邀约句

#### 屏 ⑩ 赛前 11 人合影（队长生成）
- 看到：11 个命格角色穿队服站位、每人标命格名+昵称、阵型名、球队名
- 可做：保存合影；发回群
- 去哪：发回群 → 成为新的「加入球队」入口
- 文案位：球队合影标题位 / 阵型名 / 保存与分享按钮 / 可发群一句话

### 9. 拼队设计要点

- 成员零负担：只需点链接→测自己→自动归队，无需理解「球队」概念
- 队长是唯一操作者：挑人、排位、成图都在队长端，成员不协作
- 球队链接 = 传播载体：合影发群后链接仍在，第 12、13 人继续加入，比单人卡裂变更强
- 合影放命格角色，非真人脸
- 无账号也能玩：靠球队链接/码归集成员结果（依赖 Phase 1 的结果持久化预留）

---

## 10. 设计原则（贯穿两期）

- 每屏唯一主动作
- 输入全程点选，昵称挪到保存后且选填
- 结果先给后引导，不做分享解锁
- B 线为主力，重点优化
- 保存即传播起点
- B1 只给朋友结果+挑衅，解读留到自己结果页
- 揭晓动效 1.5–2.5s
- 一键发微信/小红书可降级
- 性别必答用于生成对应性别角色
- Phase 1 即预留 Phase 2 接口
