# 《足球命格》命理到球员人设映射规则 v1

## 1. 规则目标

本规则用于把用户出生信息转成「球场角色」和「球员梗人设」。

产品口径：

> 根据你的出生信息，推算你生来就是球场上的什么角色。

注意：

- 这是娱乐测试，不是严肃命理服务。
- 结果不直接说“你就是某球星”，而是说“你的球场命格接近某类球员人设”。
- 球星名、外号和梗只作为用户理解结果的参照。
- 争议型事件梗需要卡通化、匿名化，不使用真实肖像、队徽、赛事 logo。

---

## 2. 总链路

```text
用户输入
  ↓
八字基础特征
  ↓
球场行为维度评分
  ↓
位置倾向判断
  ↓
球员人设桶
  ↓
结果卡输出
```

核心原则：

1. 出生信息决定主结果。
2. 用户自选球风只用于制造「你以为 vs 实际」反差。
3. 结果先落在匿名人设桶，再绑定球星梗参照。
4. 每个结果必须能解释成球场行为，而不是只堆玄学词。

---

## 3. 输入字段

| 字段 | 是否必需 | 用途 |
|---|---|---|
| 性别 | 必填 | 用于角色呈现、部分命理口径和后续扩展。 |
| 出生日期 | 必填 | 生成年月日柱，核心计算锚点。 |
| 出生时间 | 必填，但可选「不知道」 | 生成时柱。不知道时走降级算法。 |
| 出生地 | 必填 | 用于城市/时区/真太阳时口径，首版可先城市级。 |
| 自认球风 | 选填 | 只用于反差展示，不作为主判定。 |
| 昵称 | 选填 | 只用于分享卡个性化。 |

### 3.1 出生时间缺失处理

如果用户选择「不知道出生时间」：

- 不生成时柱或使用中性时柱。
- 降低结果置信度。
- 避免输出“命定”“绝对”类措辞。
- 结果页可显示：“因出生时间缺失，本次按三柱快速版生成。”

## 4. 命理特征层

首版只取 5 类命理特征。

| 特征 | 解释 | 产品化作用 |
|---|---|---|
| 五行强弱 | 木、火、土、金、水的相对强弱 | 决定球场底色。 |
| 日主强弱 | 用户命盘承压和主动性 | 决定主动硬刚还是借力发挥。 |
| 十神结构 | 比劫、食伤、财、官杀、印 | 决定球场行为方式。 |
| 冲合刑害 | 结构稳定度、戏剧性、冲突性 | 决定梗感、事故感、反差感。 |
| 季节/月令 | 出生季节对五行的放大 | 用于修正五行权重。 |

首版不建议使用过重的神煞体系，避免解释失控。

| 土弱 | 对抗和稳定不足 | 快乐男孩、抽象、容易失位 |
| 金弱 | 终结和杀伐不足 | 传控洁癖、犹豫、只做辅助 |

| 维度 | 主要来源 | 高分表现 |
|---|---|---|
| 凶狠指数 | 七杀、金、冲刑、身强、比劫 | 对抗强、压迫重、动作大 |
| 优雅指数 | 食神、印、水、合、火弱不过激 | 从容、脚法细、动作好看 |
| 控场指数 | 正官、正印、水土、合多 | 站位稳、节奏强、会组织 |

| 抽象指数 | 偏印、伤官、害、冲多、身弱失衡 | 喜剧效果、神经刀、反常规 |

## 8. 位置倾向规则

位置不直接由用户自选决定，而由命理结构判断。

| 位置 | 触发条件 | 典型人设 |
|---|---|---|
| 门将 | 印旺、水土重、控场高、爆点低 | 门神、心理战门将、蝎子摆尾 |
| 中卫 | 土金重、正官/七杀旺、凶狠或控场高 | 武僧、城墙、航母 |
| 边后卫 | 木旺、爆点高、控场中等、终结低 | 飞翼、摩托、左路推土机 |
| 后腰 | 金水土重、七杀/正官/印旺 | 球场恶汉、西装后腰、中场陀螺 |
| 中前卫 | 水土平衡、控场高、优雅中高 | 冷脸会计、魔笛、润滑剂 |
| 前腰 | 食神/伤官旺、优雅高、爆点中高 | 翩翩公子、舞动精灵、小法师 |
| 边锋 | 木火旺、偏财/伤官旺、爆点最高 | 内切老汉、爆点小熊、腾云大圣 |
| 中锋 | 财星旺、金火旺、终结最高 | 总裁、九五至尊、禁区杀手 |

### 8.1 位置优先级

如果多个位置同时命中，按以下规则处理：

1. 最高行为维度优先。
2. 防守型特征强于进攻型特征时，优先后腰/中卫。
3. 终结指数最高且财星旺，优先中锋。
4. 爆点指数最高且木火旺，优先边锋。
5. 控场指数最高且水/印/官旺，优先中场或后腰。
6. 抽象指数最高时，不改变位置，只改变人设风格。

### 9.1 球星参考选择规则

同一个人设桶下，按位置和次高维度选择球星参照。

```text

```

## 10. 反差机制

用户自选球风不决定结果，但用于结果页制造笑点。

| 用户自认 | 系统实际 | 展示方式 |
|---|---|---|
| 翩翩公子 | 球场恶汉 | “你以为你负责优雅，系统说你负责让对面冷静。” |
| 中场大师 | 快乐抽象派 | “你以为你在调度，其实你在制造悬念。” |
| 禁区杀手 | 中场陀螺 | “你以为你负责进球，系统说你负责把球传给别人进。” |
| 爆点边锋 | 冷脸会计 | “你以为你要起飞，系统说你先把账做平。” |
| 门线英雄 | 腾云大圣 | “你以为你该守门，系统说你应该跑到对面底线。” |

反差强度规则：

- 如果用户自认和系统结果同类：输出“你很了解自己”。
- 如果用户自认和系统结果相反：输出“系统拆穿人设”。
- 反差越大，分享卡越有传播性。

## 13. 内容安全规则

1. 不使用真实球员肖像。
2. 不使用国家队队徽、俱乐部队徽、FIFA/World Cup 官方标识。
3. 争议事件梗使用卡通化表达。
4. 避免种族、地域、政治、宗教相关贬义词。
5. 结果文案可以调侃，但不能做现实人格攻击。
6. 所有页面加娱乐免责声明。

推荐小字：

> 娱乐测试，仅供玩梗，不代表真实性格、职业能力或命运判断。
